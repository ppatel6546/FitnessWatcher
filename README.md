
# FitnessWatcher

FitnessWatcher is a personal fitness tracker website built using HTML, CSS, and JavaScript.

## Sprint 1 Goal

Allow users to add, save, and view workout records.

## Features

- Add workouts with an exercise name
- Record sets, reps, weight, and date
- Save workout records using localStorage
- Display saved workouts in Workout History
- Keep workouts saved after refreshing the page
- Validate required fields and numeric inputs

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this GitHub repository.
2. Open the FitnessWatcher folder.
3. Double-click index.html to open it in Chrome.
4. Fill out the Add Workout form.
5. Click Save Workout.
6. View your saved workout in Workout History.
